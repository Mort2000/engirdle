ENGIRDLE · ANDROID · MVP

Engirdle Android 客户端
高保真页面设计稿

单用户产品：PC 端生产内容（录入英文文章 → DeepSeek 翻译 → 本地 Qwen3-TTS 句级语音 → 打包 .readpack 局域网发布），Android 端（Flutter，仅验收 Android）下载、校验、原子导入后完全离线使用：阅读（三种译文模式）、句级/连续播放、离线词典查词、生词本。本设计稿依据 mvp_prd.md 第 6/7/9 章与 mvp_design.md 第 6.5/8/10 章绘制。

本目录结构

  • styles.css — 公共样式（设计令牌、画板、手机框、所有公共组件）
  • icons.svg — 25 个 SVG 图标 symbol，各屏通过 <use href="icons.svg#i-xxx"/> 外部引用
  • constraints.md — 公共约束（产品定位、设计原则、排除项、设计令牌、组件规格、设计假设记录 ①–⑭）
  • sNN-*.html — 17 个屏幕文件，每屏一份，独立可查看

查看提示

本设计稿使用外部 SVG 引用。Chrome / Edge 在 file:// 协议下会因 CORS 拦截外部 SVG，图标不显示——请通过本地服务器查看：

python3 -m http.server 8000
→ 浏览器打开 http://localhost:8000/

Firefox 不受此限制，file:// 直接打开亦可。
