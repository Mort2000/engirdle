服务设置 · 错误态

MOB-NET-001错误分类：连接NFR-UX-001

屏幕目的

把移动端错误分类（mvp_design.md §10：连接 / 下载 / 包格式 / 资源超限 / 数据库 / 播放器）中的「连接错误」转译为用户可理解、可操作的提示。

四类提示文案（验收要点）

无效 URL：「地址格式无效：需以 http:// 或 https:// 开头，例如 http://192.168.1.12:8766。」（输入框内联，02B 虚线区）
连接拒绝：「无法连接服务 · 连接被拒绝。请确认 PC 已开启局域网只读服务、手机与 PC 在同一网络、端口正确。」（02A 对话框）
超时：「连接超时：8 秒内未收到响应。请检查 PC 是否在线，以及手机与电脑是否处于同一局域网。」（同 02A 对话框样式）
非局域网 HTTP 被拒绝：「已拒绝：非局域网 HTTP 地址。明文 HTTP 仅限局域网；公网请改用 HTTPS。」（02B 内联，提交前拦截，不发起请求）
权限拒绝：「局域网访问权限被拒绝：请在系统设置中允许 Engirdle 访问本地网络。」（附「打开系统设置」按钮）

交互说明

  • 格式类错误（无效 URL、非局域网 HTTP）在发起网络请求之前拦截；
  • 所有错误均标注错误分类，并强调「不影响本机内容」；
  • 「重试验证」使用同一地址重新请求，不静默修改用户输入。
