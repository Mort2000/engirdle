# Engirdle Android · 设计稿公共约束

> 本文档汇总 `index.html` 设计稿中**跨屏幕通用**的约束、约定与假设。各屏幕自身的目的/交互/验收落点保留在对应屏幕 HTML 的 `.note` 标注块中。
>
> 依据：`mvp_prd.md`（2026-08-07）与 `mvp_design.md` · 已按 UX 评审（2026-08-07）采纳 4 项改进（假设 ⑪–⑭）。

---

## 1. 产品定位

“PC 生产、移动端离线听读”的单用户工具。移动端不生产内容、不联网推理、无账号云同步；导入成功后即为离线单机应用。

- **PC 端**：录入英文文章 → DeepSeek 翻译 → 本地 Qwen3-TTS 句级语音 → 打包 `.readpack` 局域网发布。
- **Android 端**（Flutter，仅验收 Android）：下载、校验、原子导入后**完全离线**使用——阅读（三种译文模式）、句级/连续播放、离线词典查词、生词本。

---

## 2. 设计原则

- **阅读优先**：纸感浅色 + 预设暗色主题，Material 3 气质的圆角与 tonal 表面。
- **默认离线**：应用不做任何后台连接与目录轮询，只有用户主动「检查更新 / 验证」时才联网。
- **行内零图标**：阅读区不放任何按钮；短按句子出句菜单、长按出词菜单，翻译与词典结果一律走底部抽屉。
- **句级交互**：渲染/播放/翻译/选词全部绑定稳定句 ID，移动端不重新分句。
- **安全导入**：临时文件 → 校验 → 事务 → 原子切换，失败保留旧版本。
- **单一播放会话**：新请求取代旧请求，无争用状态。

## 4. 排除项自查（设计中不出现）

> 全局排除项，任何屏幕都不应出现以下能力：

- 倍速 / 循环 / 播放列表 / 进度拖拽
- 锁屏后台播放与媒体通知
- 逐词高亮
- 间隔重复 / 测验 / 熟练度
- 词汇发音
- 账号与云同步
- 自动服务发现
- 跨句选择
- 任意颜色选择器

取标题前两个单词的首字母（保留原词大小写），五种书脊/纸感底色按 `article_id` 散列选取。

| 示例标题 | 缩写 |
| --- | --- |
| The Quiet Practice of Mending | **TQ** |
| Notes on Slowness | **No** |
| A Field Guide to Urban Birds | **AF** |
| Meditations on Brevity | **Mo** |

| 底色名 | 色值 | CSS class |
| --- | --- | --- |
| 陶土 | `#b26e4f` | `av a4` |
| 鼠尾草绿 | `#87977a` | `av a1` |
| 雾蓝 | `#71879b` | `av a3` |
| 燕麦 | `#c9b083` | `av a5` |
| 深李 | `#7d5d6e` | `av a2` |

> 字母与标题严格对应；状态徽章（`有更新` / `可用` / `已是最新`）按屏幕 03B / 05 规则。

### 7.2 列表信息收敛

书架/目录条目只保留：**文章名、作者、音频时长**（时长即长度参考）。下载/导入页只暴露进度百分比、MB 级大小与友好阶段名；**哈希、文件路径、`staging/` 临时目录、格式版本号（如 `readpack 1.0`）、sense ID（如 `wk.en/mend#v.1`）、词典资源 ID（如 `dict-en-zh-core @ r14`）等纯工程信息只在调试日志或归属页（屏幕 15）出现**，不进入用户主流程。

### 7.2-bis 用户文案去工程化

> 用户主流程文案中不出现下列内部术语；技术原因写入日志或归属页。

| 不要展示 | 改写为 |
| --- | --- |
| 句 ID `s-XXXX` | 「第 X 段第 Y 句」或省略 |
| `lemma` | 「原形」 |
| `sense id`（`wk.en/mend#v.1`） | 不展示（仅入库） |
| 词典资源 ID（`dict-en-zh-core @ r14`） | 「来自 Wiktionary」 |
| 文章版本 `rev N` / 制品 `r1` | 「第 N 版」（必要时） |
| `catalog vN` | 「目录已获取」 |
| 半开区间 `[7.2s, 19.4s)` | 「句末自动停止」（必要时）或省略 |
| `SHA-256` / 哈希片段 | 「完整性校验」 |
| `manifest` / `schema v1.0` / `staging/` | 「校验内容完整性」/「解包内容」 |
| `事务写入数据库` / `切换版本指针` | 「保存到本机」 |
| `制品` / `artifact` | 「版本」 |
| `查询路径：未命中 → 命中` | 「已找到相关释义」/「未找到」 |
| `自动消歧` | 不展示（设计排除项） |

### 7.3 手势约定（**短按取消优先**）

> 假设 ④ + ⑭：贯穿全部阅读相关屏幕（06 / 07 / 08 / 09 / 10 / 11 / 14）。

- **短按 = 取消优先**：界面存在任何开启态（句菜单 / 词菜单 / 选区 / 底部抽屉）时，短按优先执行**取消**——关闭菜单 / 取消选区 / 收起抽屉，回到无开启态。
- **仅在无开启态时**，短按句子才打开「句子菜单」（底部抽屉统一形态：单句翻译 / 单句朗读 / 从此开始朗读）。
- **长按句内词** = 词菜单（英英翻译 / 英中翻译 / 复制）。
- **滚动 / 翻页手势**不触发任何菜单。

### 7.4 行内零图标

阅读区不放任何按钮或图标：

- 当前播放句以**暖色底 + 左侧竖线**（`.st.play`）标识，不使用扬声器图标；
- 当前选词以**浅绿底 + 描边**（`.selw`）标识；
- 翻译与词典结果一律走**底部抽屉**（`.sheet`），不在原文区内联展开；
- 暗色主题下播放高亮同步适配（屏幕 13B）。

### 7.5 错误分类体系

> 出自 `mvp_design.md §10`。屏幕 02 / 04 / 10 等的错误反馈文案遵循此分类。

| 分类 | 出现屏幕 | 文案风格 |
| --- | --- | --- |
| 连接错误 | 02 | 「无法连接服务 / 连接被拒绝 / 连接超时」+ 三步排查 |
| 下载错误 | 04A 虚线区 | 「SHA-256 校验失败 / 大小不一致」+ 已删临时文件、未进入导入 |
| 包格式 / 资源超限 | 04B 步骤 1–2 | 拒绝路径穿越 / 重复路径 / 链接 / 超限 |
| 数据库错误 | 04B 步骤 5 | 失败回滚 + 当前版本不受影响 |
| 资源缺失 | 10B 状态 B | 词典未安装，文章/翻译/播放不受影响 |

**通用约定**：所有错误均标注分类，并强调「不影响本机内容」；格式类错误（无效 URL、非局域网 HTTP）在发起网络请求之前拦截。

### 7.6 替代状态容器（设计板约定）

`.altbox`（虚线边框）用于在同一屏幕内表达「同一组件的另一状态」，避免重复绘制整块屏幕。运行时只显示与当前状态匹配的一个，虚线区不参与运行时渲染。

## 9. 设计假设记录

> 文档未明确处的合理取值；**实现时以 PRD / 设计文档为准**。

- ① **封面组件**：取标题前两个单词的首字母并保留原词大小写（The Quiet…→TQ、Notes on…→No、A Field…→AF、Meditations on…→Mo），五种书脊底色（陶土 / 鼠尾草绿 / 雾蓝 / 燕麦 / 深李）按 `article_id` 散列选取。
- ② **列表信息收敛 + 用户文案去工程化**：目录与书架条目只显示文章名、作者、音频时长；下载/导入页只显示进度百分比、MB 级大小与友好阶段名（「下载中 / 校验完整性 / 解包内容 / 保存到本机 / 清理旧版本」）；句 ID、`lemma`、`sense id`、词典资源 ID、`SHA-256`、`staging/` 临时路径、`manifest`/`schema` 等纯工程信息只在调试日志或归属页（屏幕 15）出现，不在用户主流程展示（详见 §7.2 与 §7.2-bis）。
- ③ **连接策略**：应用默认离线、不后台连接/轮询；「检查更新」按钮固定在书架顶部卡片并显示上次检查时间，目录结果仅当次展示、不缓存。
- ④ **手势分工**：短按 = 取消优先——界面存在任何开启态（句菜单 / 词菜单 / 选区 / 底部抽屉）时，短按优先执行取消（关闭菜单 / 取消选区 / 收起抽屉），回到无开启态；仅在无开启态时，短按句子才打开句菜单（底部抽屉统一形态：单句翻译 / 单句朗读 / 从此开始朗读）；长按句内词 = 词菜单（英英翻译 / 英中翻译 / 复制）；滚动/翻页手势不触发句菜单；阅读行内零图标，播放句以暖色底 + 左竖线标识。
- ⑤ **生词本排序**默认按保存时间倒序。
- ⑥ **排版档位**：字号 14/16/18/20、行高 1.5/1.8/2.0、边距 窄/标准/宽。
- ⑦ **导入上限**采用 `design §6.5` 候选默认值（ZIP 512 MiB / 展开 1 GiB / 64 条目）；验证连接以读取 catalog 成功为准，未验证的地址允许保存但提示先验证。
- ⑧ **英中对照**作为整文渲染模式保留（MOB-READ-002），全文一次性铺排、无逐句开关。
- ⑨ **〔待用户决策〕单句翻译不内联展开**，统一走底部抽屉（屏幕 06B）——这是对 MOB-READ-003「单句译文展开/收起」字面表述的偏离，以抽屉实现其“按需查看单句译文”的意图，需确认。
- ⑩ **词典释义语言切换**：词典抽屉默认释义语言随长按菜单入口（英英翻译/英中翻译），英英仍为首选序与缺省值；MOB-DIC-003 的“可展开英中”由逐义项展开调整为**整抽屉语言切换**。
- ⑪ **存词一步保存**（UX 评审 2026-08-07 后采纳）：词典抽屉点「保存该义项」即直接入库——义项选择本身就是 MOB-VOC-001 要求的用户显式选定义项动作，取消原二次确认页；保存以 snackbar 即时反馈并在其存活期内可撤销，抽屉保持打开可继续查词，完整快照改在生词详情（屏幕 12B）查看（屏幕 11）。
- ⑫ **播放替换提示降噪**（UX 评审 2026-08-07 后采纳）：「新请求取代旧请求」snackbar **仅在连续播放会话被新播放请求取代时提示一次**；单句与单句之间的切换不再弹出，由控制条句标识与播放高亮表达（MOB-AUD-004 语义不变，屏幕 14B）。
- ⑬ **空态补齐**（UX 评审 2026-08-07 后采纳）：新增屏幕 17——空书架（本地 0 篇，按是否已配置服务地址给出「检查更新」/「先去配置服务地址」引导，MOB-LIB-001）与空生词本（说明保存来源路径，列表骨架与屏幕 12 一致，MOB-VOC-002）。
- ⑭ **短按取消优先**（UX 评审 2026-08-07 后采纳）：为 ④ 的手势分工补充取消优先语义——存在任何开启态时短按先取消并回到无开启态，仅无开启态时短按句子才打开句菜单；滚动/翻页不触发句菜单。
