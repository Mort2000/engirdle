## 1. 评审范围与结论

对设计稿 16 屏逐屏检视后做整体 UX 评审。总体结论：设计在需求忠实度、状态诚实性（默认离线、原子导入、失败保护）和渐进披露上质量良好，**无阻塞性 UX 风险**；主要问题集中在高频交互的成本上。

评审发现的 4 项改进已被采纳并落入设计稿：

| 编号 | 改进 | 设计稿落点 |
|---|---|---|
| UX-A1 | 存词一步保存：词典抽屉点「保存该义项」即保存（义项选择本身即用户显式动作），以 snackbar 提供撤销；原二次确认页改为保存反馈展示，完整字段快照在生词详情查看 | 屏幕 10 / 11 |
| UX-A2 | 播放替换提示降噪：snackbar 仅在连续播放被新请求取代时出现；单句间切换由控制条状态表达，不再弹提示 | 屏幕 14 |
| UX-A3 | 补齐空态：空书架（未安装文章，含已配置/未配置服务两种引导）与空生词本 | 屏幕 17（新增） |
| UX-A4 | 短按取消优先：存在任何开启态（句菜单、词菜单、选区、抽屉）时，短按优先执行取消；界面无开启态时短按句子才打开句菜单 | 屏幕 06 / 09 标注、页脚假设④ |

## 2. 暂缓项

以下发现本次不落入设计稿，待第一版实现完成、用户（作者本人）实际使用评估后再决定是否立项。每项记录问题、候选方案和再评估触发信号。

### UX-S1 句菜单形态：底部抽屉 → 浮动菜单

- 问题：「点句听」是应用最高频操作，当前每次需 2 次点按并展开遮蔽约 40% 屏幕的底部抽屉；三个选项的菜单用抽屉承载偏重。
- 候选方案：改为靠近被点句子的浮动上下文菜单（与屏幕 09 词菜单同形态），同样不违反「行内零图标」约定；单句翻译结果仍走底部抽屉（UX-A 系列不变）。
- 再评估信号：实际听读中对句菜单的使用频率与误触反馈；若日均触发明显偏高即重做。

### UX-S2 控制条「重播本句」按钮

- 问题：听读场景「没听清，重听当前句」是刚需，目前需重新走句菜单（2 次点按）。
- 候选方案：播放控制条增加「重播本句」键，按当前模式重放当前句区间；不构成 MVP 排除的「循环」功能。
- 再评估信号：用户反馈重听操作繁琐，或观察到频繁通过句菜单重放同一句。

### UX-S3 连续播放自动滚动

- 问题：连续播放长文时，播放句高亮很快滚出屏幕，视觉锚点失效，用户被迫边听边手动跟滚。当前为 PRD §9 明确排除项，设计合规。
- 候选方案：连续播放模式下滚动跟随当前播放句（单句播放不滚动）；实现成本低，建议作为 MVP 后第一个重新评估的排除项。
- 再评估信号：MVP 验收完成后即重评；无需等用户反馈积累。

### UX-S4 目录结果带时间戳缓存

- 问题：手动刷新的目录结果仅当次展示、不缓存（设计假设③），离开书架再进入后「有更新」徽章消失。
- 候选方案：缓存上次目录结果并显示检查时间，下次刷新前以「可能已过期」视觉降级展示。
- 再评估信号：用户反馈「刚才明明看到更新」类困惑。

### UX-S5 生词删除改为 snackbar 撤销

- 问题：生词删除当前为确认弹窗；低风险可逆操作用弹窗偏重（文章删除保留弹窗不变）。
- 候选方案：删除即时生效 + snackbar 撤销（与 UX-A1 的存词撤销同一模式）。
- 再评估信号：与 UX-A1 撤销模式的用户反馈一并评估，保持两处一致。

### UX-S6 短按/长按与文本选择的微交互细节

- 问题：选区存在时点按的精确行为、滚动/翻页中的 touch slop、不同 Android 版本的选择菜单差异，设计稿层面无法完全定义。
- 候选方案：UX-A4 已确立「取消优先」原则，其余细节留阶段 0 Flutter 选词原型实测后补充进设计稿标注。
- 再评估信号：阶段 0 原型验证结果（此为 MVP 验收门槛之一，见 mvp_feasibility.md）。

## 3. 评审确认无阻塞风险的部分

- 默认离线 + 手动刷新的连接策略（屏幕 03/16）：状态诚实，信任模型清晰。
- 两级手势分工（短按句级 / 长按词级）：消解 MOB-READ-003 的手势冲突要求。
- 翻译统一走抽屉：阅读流无回流、位置不丢。
- 错误分类与文案（屏幕 02/04）：符合 mvp_design.md §10 的移动端错误分类，可操作。
- 列表信息收敛与归属页集中展示工程信息（屏幕 03/05/15）。
- 排版三预设主题与四档字号（屏幕 13）：满足 NFR-UX-001。
